# 寶島社會大冒險

五年級上學期社會科期中考複習遊戲（單一 HTML 檔，直接用瀏覽器開啟 `index.html` 即可）。

## 玩法
- **闖關問答**：10 題選擇題、3 顆愛心、限時 25 秒，答越快分數越高，答對附解說。
- **翻牌配對**：12 張牌，把名詞和說明配成對。
- **快問快答**：60 秒是非題，鍵盤 O／X 也能作答。
- **錯題本**：答錯的題目自動收集，可重練，答對就移除。
- **護照集章**：單元闖關拿到 2 顆星以上就蓋章（進度存在瀏覽器）。

## 範圍
1. 臺灣的位置與範圍　2. 臺灣的地形　3. 臺灣的氣候與水文
4. 史前文化與原住民族　5. 大航海時代與鄭氏時期

## 修改題目
題庫在 `index.html` 的 `UNITS` 陣列：
- `mc`：`[題目, 正確答案, [錯誤選項×3], 解說]`
- `tf`：`[敘述, true/false, 解說]`
- `pairs`：`[名詞, 說明]`
